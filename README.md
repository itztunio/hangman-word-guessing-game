# Hangman Word Guessing Game

A Python-based Hangman Word Guessing Game using ASCII art and random word selection.

## Project Description
Hangman is a word-guessing game in which the player tries to guess a hidden word one letter at a time. The player has a maximum of 6 wrong attempts to guess the word correctly.

## Features
- Random word selection using Python's `random` module.
- Hidden word displayed using underscores.
- ASCII Hangman drawing updates after incorrect guesses.
- Tracks guessed letters.
- Prevents repeated guesses from reducing attempts.
- Displays win and game-over messages.

## Technologies Used
- Python 3
- Random module
- ASCII art

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run the following command:

```bash
python hangman.py
```
